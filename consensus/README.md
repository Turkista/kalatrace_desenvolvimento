# Consensus

## Função Arquitetural

Consensus representa a capacidade de análise de consenso e divergência científica do KALATRACE.

## Responsabilidade

Avaliar o grau de concordância, controvérsia e estabilidade de determinado conhecimento dentro do universo científico.

## Categoria

Camada:
Arquitetura Cognitiva

Tipo:
Especialista Cognitivo

## Significado do Nome

Consensus representa a capacidade de compreender como o conhecimento científico se distribui entre diferentes fontes, pesquisadores e linhas de investigação.

O módulo não determina a verdade científica, mas analisa o nível de concordância existente.

## Papel no Sistema

Consensus é responsável por:

- análise de consenso científico;
- identificação de divergências;
- avaliação de controvérsias;
- acompanhamento de mudanças de paradigma;
- análise da estabilidade do conhecimento.

## Comunicação

Recebe informações de:

- Knowledge
- Graph
- Evidence Registry
- Validation Engine
- Research Engine

Comunica-se principalmente com:

- Dynamic
- Prediction
- Simulation
- Cognitive Orchestrator
- Metacognition

## Limitações

Consensus não valida uma informação sozinho.

Consensus não substitui evidências científicas.

Sua função é avaliar o comportamento coletivo do conhecimento científico.

A validação formal pertence à camada epistemológica.
